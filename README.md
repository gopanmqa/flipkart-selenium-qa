# Flipkart — Selenium QA Automation

## Project Overview

A personal QA automation project focused on testing key Flipkart web application workflows using Selenium WebDriver.

The project demonstrates web automation, functional testing, regression testing, test design, and AI-assisted QA practices.

## Testing Scope

* Functional Testing
* UI Testing
* End-to-End Testing
* Regression Testing
* Smoke Testing
* Sanity Testing
* Positive Testing
* Negative Testing
* Exploratory Testing
* Compatibility Testing
* Test Automation
* AI-Assisted Testing

## Application Areas

The automation scope includes key e-commerce workflows such as:

* Homepage navigation
* Product search
* Search suggestions
* Product listing
* Product filtering
* Product sorting
* Product details
* Cart operations
* Product quantity
* Navigation
* Form and validation checks

## Automation Framework

**Selenium WebDriver**

The project demonstrates Selenium-based browser automation including:

* Web element identification
* Browser interaction
* Assertions
* Explicit waits
* Test execution
* Reusable automation components
* Page Object Model principles

## Planned Automation Coverage

The automation suite can cover:

1. Open Flipkart
2. Search for a product
3. Validate search suggestions
4. Validate search results
5. Apply product filters
6. Apply sorting
7. Open product details
8. Validate product information
9. Add product to cart where supported
10. Validate cart information
11. Validate navigation and UI behavior

## Automation Design

The automation approach can use the **Page Object Model (POM)** to separate page interaction logic from test scenarios.

Example conceptual structure:

```text id="r4n1qv"
flipkart-selenium-qa/

├── pages/
├── test-data/
├── reports/
└── README.md
```
